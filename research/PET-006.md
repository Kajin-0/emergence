# PET-006 — Functional emergence: complexity separation and population certificates

2026-11-24T02:23:18Z. DERIVED internally; no novelty or independent proof certification. Explicit compositional models, not evidence about frontier AI. No numerical simulation required.

## Operational definition

Given ground-truth primitive operators P_i and learned approximants A_i(t), define task word w=i_1...i_l with actual composition P_w=P_{i_l}...P_{i_1}, A_w(t)=A_{i_l}(t)...A_{i_1}(t). Use ordinary functional error E_w(t)=||A_w(t)-P_w||_F (equivalently RMS over appropriately weighted basis probes). For translations use Euclidean displacement, equivalent to Frobenius error between homogeneous affine matrices. Newly functional at horizon T relative to checkpoint 0 means E_w(0)>delta, E_w(T)<=delta. This is endpoint acquisition, not first-passage timing or guaranteed persistence for arbitrary learning. Held-out grammar contains compositions never presented in training; syntactic distinctness alone need not imply distinct target functions. In hardness construction below target functions are distinct and never primitive targets. Architecture explicitly composes known primitives; no claim it independently learns the composition operation.

## PET-006A: constant-margin functional discovery hardness (DERIVED)

Decision whether ANY untrained word becomes functional after ONE gradient step is NP-complete for a family of affine translation learners, even though:
- each primitive has squared-error loss with identity Hessian, full supervision, and exact solution;
- target and initial translation components are small integers, primitive initial discrepancy at most sqrt(3);
- each word's initial and future functional errors are exactly computable in polynomial time, and every word's error decreases monotonically;
- all grammar words initially fail; true functions are distinct; fixed threshold 3/5; passing error 1/2, all failing errors >=sqrt(2)/2 at T=1.

Proof by exact cover by 3-sets (X3C; NP-complete). Let universe U={1,...,m}, indexed triples S_1,...,S_n. Work in R^(m+n+3) with orthogonal coverage coordinates e_j (m), identity tags f_i (n), two mandatory tags g_1,g_2, and sentinel h. Each primitive is a translation x -> x+b_i. Its true vector b_i^*, initial error v_i=b_i(0)-b_i^*. For each triple i create two choice tokens:
- include: target f_i, initial error sum_{j in S_i} e_j;
- exclude: target 0, error 0.
For each universe element j create mandatory offset token with target 0 except j=1 target g_1; error -e_j. Mandatory sentinel token has target g_2 and error h. Assume nonempty universe. Grammar: first choose exactly one of each include/exclude pair in index order, then all m offsets and sentinel. This regular layered grammar has polynomial representation and 2^n words. Every word has distinct target translation g_1+g_2+sum_i selected f_i; no target equals any primitive target. Each training example is an individual primitive (e.g. target output on input 0), never a whole grammar word.

Train by L=1/2 sum_i ||b_i-b_i^*||^2. Independent simultaneous gradient descent with eta=1/2 gives b_i(t)=b_i^*+2^-t v_i for integer t. Hessian I; all primitive and word errors nonincreasing. For choice vector a in {0,1}^n, the actual composition error vector is
\[
2^{-t}\left[\sum_{j=1}^m\left(\sum_{i:j\in S_i}a_i-1\right)e_j+h\right].
\]
Hence E_w(0)>=1 and
\[
E_w(1)=\tfrac12\sqrt{1+\sum_j(\sum_{i:j\in S_i}a_i-1)^2}.
\]
An exact cover gives 1/2; noncover has at least one nonzero integer residual, so E>=sqrt(2)/2. With delta=3/5, YES margin 1/10, NO margin sqrt(2)/2-3/5>0.107. Therefore discovery iff X3C has an exact cover; certificate word checked by integer arithmetic in polynomial time. No numerical precision issue; all coefficients bounded, polynomial construction size. One qualifying word per exact cover. Exact counting is #P-hard under the standard counting-X3C hardness reduction (verify reduction convention before claiming parsimonious hardness for #X3C itself), and #P membership immediate. This construction is parsimonious from #X3C to emergence count. Unlike PET-001, the objective is genuine functional discrepancy from a target composition, not a Boolean clause score attached to a dummy system. Nonetheless adversarial primitive initialization and supplied grammar encode X3C; not average-case hardness or a realistic neural mechanism. Constant absolute error gap is not necessarily constant normalized gap as dimension/word length grows.

## PET-006B: compressed exact joint moments (DERIVED; established tensor machinery)

For d-dimensional real linear primitive matrices, assume matrices at both checkpoint and horizon are given or can be calculated from known learning dynamics. Example: direct matrix least squares, simultaneous GD eta in (0,1), A_i(t)=P_i+(1-eta)^t(A_i(0)-P_i); future coefficients analytic without full training. If P_i and A_i(0) are spectral contractions, all learned matrices remain contractions. For arbitrary matrices require a known bound B>=max_{w,t in {0,T}} E_w(t)^2. Contractions yield B=4d for all lengths. Define normalized errors s_0(w)=E_w(0)^2/B and s_T(w)=E_w(T)^2/B in [0,1]. Threshold a=delta^2/B.

Let z_w=(vec P_w, vec A_w(0), vec A_w(T)) in R^D, D=3d^2 (column vectorization). Initial z_empty repeats vec I. Appending i gives z_{wi}=M_i z_w with block diagonal M_i=diag(I_d kron P_i,I_d kron A_i(0),I_d kron A_i(T)). The two normalized squared errors are quadratic forms z^T Q_0 z,z^T Q_T z. Any polynomial p(s_0,s_T) of total degree <=q is a polynomial in z of degree <=2q; represent each homogeneous component by contraction with z^(tensor r). For independent uniform choices in layers alphabet I_j,
\[
Z_r(j)=\mathbb E[z_{w_{1:j}}^{\otimes r}]
=\left(\frac{1}{|I_j|}\sum_{i\in I_j} M_i^{\otimes r}\right) Z_r(j-1).
\]
Thus compute E[p] exactly by linear contractions, no enumeration of product(|I_j|) words. Same for independent nonuniform rational weights; regular grammars can be handled by adjoining a finite automaton state, summing allowed paths and normalizing, with care about duplicate accepting paths (deterministic/unambiguous or path distribution specified). This is weighted-automaton tensor/Hadamard algebra, not new by itself. Dense naive arithmetic upper bound O(poly(q)*l*n*D^(4q)) for total degree q in squared errors (n max layer size), since highest tensor order is 2q and a dense multiply costs O(D^(4q)). Kronecker structure can reduce constants/exponents; no bit complexity or practical speedup claimed. For homogeneous layers use repeated transfer matrix powers in O(log l) matrix multiplications, but length of witness and exact rational bit complexity can grow with l.

## PET-006C: deterministic emergence-population interval and witness (DERIVED; no margin oracle)

Let 0<g<min(a,1-a). Choose integer q>=1 and eta=exp(-2qg^2). Define degree-q Bernstein/binomial-tail polynomial
\[
B_b(s)=\sum_{k/q>b}{q\choose k}s^k(1-s)^{q-k}.
\]
Hoeffding gives B_b(s)<=eta for s<=b-g, and 1-B_b(s)<=eta for s>=b+g. All values in [0,1]. Define event I(w)=1{s_0>a, s_T<=a}, and shifted two-checkpoint polynomial tests
\[
p_-(w)=B_{a+g}(s_0)(1-B_{a-g}(s_T)),\qquad
p_+(w)=B_{a-g}(s_0)(1-B_{a+g}(s_T)).
\]
Pointwise p_-<=p_+. If I=0 at least one lower-test factor <=eta, so p_-<=eta; if I=1 both upper-test factors >=1-eta, so p_+>=(1-eta)^2>=1-2eta. Therefore for every word, even on thresholds,
\[
p_--\eta\le I\le p_++2\eta.
\]
Write f=Pr(I=1) under the prescribed word distribution. Joint moments from PET-006B with squared-error total degree 2q (max tensor order 4q) yield rigorous interval
\[
\max(0,\mathbb E p_--\eta)\le f\le
\min(1,\mathbb E p_++2\eta).
\]
For uniform distinct words multiply by grammar size to bound count (round inward with certified exact/rational bounds). No need to certify a universal margin in advance. Let bmass=Pr(|s_0-a|<2g or |s_T-a|<2g). Away from this band p_+-p_-<=2eta (both lower factors near 1 for true events; upper <=eta for false events). Hence interval width <=bmass+5eta (clipping can only shrink). A uniform 2g margin makes width <=5eta. If no such margin, the computed interval remains valid but can be wide. eta may be replaced by any certified rational upper bound; with rational matrices, thresholds and weights moment computation exact in principle, numerical arithmetic needs error bounds.

If E[p_-]>eta, a witness can be found deterministically by conditional expectation: at each grammar layer choose a permitted next token whose conditional mean of p_- is at least the current conditional mean. Such a choice exists by the averaging identity. All conditional means can be computed by same transfer recursion from known prefix state, including suffix distribution. At a leaf p_->eta implies I=1. Complexity at most polynomial extra in l,n over computing moments (naive recomputation). With true event mass f>3eta and no band for true events, lower test has E[p_-]>=f(1-eta)^2; use actual certificate rather than this conservative sufficient condition. In general no guarantee of witness discovery for rare events or tiny gap. At fixed q,d, dependence on word length is polynomial rather than enumeration size; tensor dimension D^(4q) and naive cost O(poly(q)*l*n*D^(8q)) can be prohibitive. Needed q scales as O(g^-2 log(1/eta)); as normalized gap shrinks or desired error is exponentially small, algorithm loses advantage. No contradiction with NP-hardness; no universal computational speedup. Monte Carlo is a strong baseline for abundant events and generally much cheaper, but provides probabilistic rather than deterministic certificates. Do not claim practical superiority without a matched benchmark. Potential next question: exploit symmetry, low tensor rank or algebraic invariance to replace exponential moment dimensions and obtain a genuinely useful compressed certificate from a representation learned without supplied factorization.

## Checks and limitations
