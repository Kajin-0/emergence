# PET-012 switching experiment protocol — frozen before execution

Question: can an exact lazy-tree continuation reproduce full ReLU GD across nonzero training activation switches and preserve held-out output certificates? Compare total wall time and storage, not merely update arithmetic. Theoretical static halfspace reporting data structure is NOT implemented; prototype uses recursively split enclosing boxes and coalesces uniform siblings during reclassification, retains original states, and caches node statistics. No claim of output-sensitive runtime for prototype.

Single fixed run: NumPy float64, single BLAS thread, seed 12; N=16384,d=2,m=4, X=[(1,0),(-1,0),(0,1),(0,-1)], y=[-0.5,0.7,0.8,0.6], eta=.05, T=300, all weights trained by simultaneous GD. Four equal clusters around (a,w_x,w_y)=(.3,+/-.8,+/-.8), independent uniform noise +/- .03, divide by sqrt(N). Replace final 64 neurons in positive-positive cluster with a=.6+uniform(-.03,.03), w_x=uniform(.005,.045), w_y=.8+uniform(-.03,.03) before scaling, to encourage a small switching cohort. Fixed evaluator: 720 evenly spaced unit-circle queries and threshold .5; record initial/final output bounds and acquisition decisions as in PET-011. No tuning if zero switches, slowdown or low coverage.

Initial groups by exact mask; recursively subdivide at median along largest reference-coordinate spread only when needed. Each node caches static min/max box and Gram. For a group, pull each preactivation to reference coordinates, use box support interval to prove uniform sign; when ambiguous recurse (singleton exact), collapse if both children's final masks match. Permanent frontier changes only if actual masks differ within old group. Propagate P by exact common M. For each frontier node compute exact Gram via P S0 P^T. Reclassify at every step including final. Track count of distinct switching neurons per step (including repeated switches over time), group history count, visits, cache size, total stored numeric entries incl source states, masks and active transforms. Compare direct vectorized GD from same start, track all masks (including final), compare each checkpoint training output outside timing or using stored output arrays; compare initial and final held-out output with direct. Require all discrepancies <1e-10 for training outputs and all query intervals enclose direct outputs to 1e-10; certified decisions zero errors. Floating point not interval-certified. Timings count construction, all training/reclassification, initial/final query costs; report one-run timing, no claims of robust wall-clock scaling or comparison with optimized halfspace solver. Direct baseline includes switch counts for matched diagnostic. Primary discriminator: >0 actual switches with exact training outputs, correct query certificates, and no repeated full microscopic reconstruction; report speed even if <1x. Park prototype if slowdown; no reruns for optimization. $0 additional spend.
