## Exact continuation

Use PET-011 scalar two-layer bias-free ReLU, N neurons, d-dimensional input, m training examples, squared error and simultaneous full-batch GD; at zero use derivative 0. All initial weights v_j=(a_j,w_j) known. Partition by initial training mask and build a balanced binary reference tree per mask. For each static node B, store reference Gram S_B^0=sum_{j in B} v_j(0)v_j(0)^T. Maintain disjoint frontier nodes B with common transform P_B such that v_j(t)=P_B v_j(0) for all j in B and previous mask. Initially P=I. For input ell_i=(0,x_i), current activation is
\[
(P_B^T\ell_i)^Tv_j(0)>0.
\]
An old active bit is violated in the closed halfspace <=0, an old inactive bit in the open halfspace >0. Exact strict predicates assumed, including ties; zero normal handled directly. No invertibility required. Refine each frontier node into uniform-mask subnodes by geometry queries, at worst singleton leaves. Inherit parent P for each child. For uniform-mask B,
\[
S_B=P_B S_B^0 P_B^T,\quad
f(x_i)=\sum_B\sigma_{Bi}e_0^TS_B\ell_i,\quad
r_B=m^{-1}\sum_i\sigma_{Bi}(f(x_i)-y_i)x_i.
\]
Update P_B by left multiplication with M_B=[[1,-eta*r_B^T],[-eta*r_B,I]]. Induction: refinement changes only partition, not weights; outputs and residual exact, common update applies to each individual neuron. Thus exact for any finite number of GD steps regardless of changes. No claim of finite-precision exactness. PET-011 unseen-output bound applies to final frontier with reference box center c and radius vector r, using halfwidth u=|P_B^T ell|^T r. Error bound sum_B sqrt(n_B S_B[0,0]) max(0,u-|ell^TP_B c|). Initial/final intervals certify threshold acquisition/nonacquisition or abstain; not first passage or semantic discovery.

## Conditional event-sensitive complexity (not measured)

Depth h=O(log N), S_t distinct changed-mask neurons at checkpoint t (across time, not bit flips), G_t^- frontier count before reclassification. Store separate static halfspace reporting structure per tree node. Query opposite halfspace for each active frontier node and input; union reports (<=m S_t). Mark switched leaves and ancestors in O(S_t h) time. Split into maximal untouched subtrees plus marked leaves. Untouched masks remain exact, recompute switched masks in O(m) per leaf; inherit P. Optional coalescing of uniform siblings with same P and mask. G_t<=min(N,G_0+h sum_{u<=t}S_u). No merging across differing histories assumed. In augmented dimension 3 (d=2), established static halfspace reporting gives O(log n+k) query, O(n) space (Afshani & Chan 2009); earlier randomized method has expected O(n log n) preprocessing, O(log n+k) expected query, check space tradeoff. Preprocessing sum_B C_build(|B|), space sum_B C_space(|B|); if linear-space O(n log n) build primitive available then O(N log^2 N) preprocessing and O(N log N) space. Older variant may add log-log space factor. For fixed d=2 under optimal query primitive, postconstruction arithmetic cost:
\[
O(\sum_{t=0}^T m G_t^-\log(N+1)+m\sum_t S_t+h\sum_t S_t+\sum_{t=0}^T mG_t).
\]
Include initial O(Nm) mask construction, tree build, source storage, exact predicates; query cost separate. For arbitrary dimension use corresponding geometry/matrix bounds. This is a conditional reduction to known data structures, not a new geometric theorem or measured runtime. Count of switches alone insufficient: frontier grows with history; still advances each step. Retains original coordinates, no total memory compression.
